# THE WORLD IN ONE DAY — Monday 23 November 2026

A program that draws one newspaper image summing up Monday 23 November 2026 in pure Node.js stdlib — its own PNG encoder, its own 5×7 bitmap font, seven pictograms, 50 sourced stories across 7 regions, a UTC timeline, and a date check. No network, no image API; two runs write byte-identical bytes.
